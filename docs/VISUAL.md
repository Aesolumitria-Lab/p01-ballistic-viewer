# 视觉规范与实现

方向：深海黄昏的像素炮兵阵地。16 位像素画风、硬边 HUD。所有画面、精灵、音效均由代码程序化生成，不使用外部素材、字体或依赖。

本文前半是设计意图，后半是实现说明。设计意图中个别细节（如沉船剪影、墓碑等）未必逐项实现，实际效果请以运行画面和代码为准。帧结构见 [FRAME_CONTRACT.md](FRAME_CONTRACT.md)。

## 画面构成

- 舞台逻辑分辨率 960 x 540（96 x 54 格，每格 10 像素），CSS 放大并 `image-rendering: pixelated`。
- 页面由顶栏（轮次、风、水位、播放控制）、四席卡片、舞台、事件流和底部时间轴组成。`U` 键或 `?ui=0` 隐藏 HUD。
- 面板风格：直角、硬阴影、1 像素描边；字体用等宽字体栈；窄屏时布局折叠。
- 1366 宽度的笔记本会隐藏顶栏的静音和全屏按钮以保住读数，快捷键仍可用。

## 调色板

基础色定义在 `web/js/shared/contracts.js`（`P01.palette`），皮肤在 `web/css/theme.css`。

- 天空：`#07101c`、`#0d2433`、`#1b4a58` 的竖直渐变，落日 `#ffb56b`。
- 海：`#12384a`、`#0c2633`，泡沫 `#a8f3ff`。
- 地形：泥土 `#6b4226`、`#7d4f2d`、`#54321d`，草皮 `#4f8f5a`，基岩 `#2d3a4b`。
- 四席颜色（色盲可区分，另有图形纹样）：席位 0 青 `#35e0d0`，1 琥珀 `#ffb340`，2 紫 `#b07cff`，3 青柠 `#9fe35a`。
- 武器：火箭、手雷、钻头的代号和颜色见 `P01.weapons`。

## 场景与角色

- 地形用离屏 canvas，按脏格增量重绘；爆炸边缘有焦痕。
- 水面为多层波浪，水位上涨有动画；投射物入水有水花。
- 背景为程序化天空、云和风迹，风越大流线越密越快。
- 虫以队伍色头巾区分；当前行动的虫有指示；受伤闪白并飘伤害数字；死亡碎成像素粒子；落水有水花。
- 投射物有尾迹和光晕，手雷在生命末段变红闪烁。
- 瞄准阶段显示实际弹道虚线和落点圈，另有一条“无风参考线”，可用 HUD 上的 NO WIND 开关控制。

## 爆炸与打击感

爆炸由短暂的暖色闪光、火球、冲击波、碎片和烟组成，配合相机抖动；击杀显示 KO 字样并有短暂的慢镜停顿（`koHold` 帧，属于帧时间轴，不影响 trace）。多次同时爆炸只叠加一层闪光，避免过曝。手雷反弹有火花，钻头挖掘有泥土喷射并带轻微震动。

## HUD

- 顶栏：地图名、seed、轮次、风表、水位、播放控制、速度、静音。
- 席卡：bot 名、当前行动标记、三条虫的分段 HP 与手雷/钻头数量、总 HP、累计伤害、存活数；死亡席位灰度化。
- 事件流：最多保留最近若干条（开火、爆炸、反弹、挖地、死亡、涨水）。
- 时间轴：按轮分刻度，带开火、爆炸、死亡、涨水标记，可拖动。
- 终局：获胜席位横幅与统计，按钮有 REMATCH、NEXT MAP、WATCH AGAIN。

## 音效

全部由 WebAudio 程序化合成，可静音。

- 母线：立体声声像（爆炸按 x 坐标左右声像）、卷积混响 send、压缩器；同帧同类音效限流，防止叠爆。
- 音色区分火箭、手雷、钻头的发射；另有爆炸、弹跳、挖掘、入水、涨水、KO、轮次、跳跃、终局等提示；播放时有随风力变化的海风底噪，暂停和 seek 时淡出。
- 默认开启，但浏览器要求先与页面交互（点击或按键）才能出声。静音偏好保存在 localStorage 的 `p01.muted.v2`；`?muted=1` 强制静音（Remotion 渲染时建议使用）。

## 相机

模式：`full`（全图）、`auto`（跟随动作，爆炸抖动）、`follow:<seat>`（跟随某席，键 `1`-`4`）、`manual`（滚轮缩放、拖拽，双击复位）。`C` 键循环切换。相机按帧步进的指数滤波，可从任意帧重新推导，保证 seek 结果一致。

## 调试与导出

- `debug=1` 或 `D` 键：网格、坐标、tick、hash、FPS 叠加。
- `ui=0`：只留画布。
- `capture()`：导出当前画布为 PNG dataURL（960 x 540）。
- 关键事件跳转：`,` 与 `.`；跳轮：`PageUp` 与 `PageDown`。

预览页：启动服务后访问 `http://127.0.0.1:8765/js/visual/_preview.html`。

## 实现约定

- 核心先绘制，再调用 `onFrame`；视觉层的第一个图层绘制时就准备好当前帧状态。视觉层不创建时钟，不修改核心的帧、地形或相机。
- 地形通过 `view.timeline.getTerrainSnapshot(index).rows` 获得，只在 `gridVersion` 变化时比较并重绘脏格及其四邻格；焦痕以初始地形判断；支持 seek 回退。
- 爆炸震屏优先使用核心相机的抖动，钻地和涨水补充微震。
- 视觉随机只用 `P01.util.rng`。

## 验证状态

- 已做：`node --experimental-default-type=module web/js/visual/selftest.mjs`，对样例检查乱序 seek 与顺序绘制的绘制指令一致、绘制参数无 NaN/Infinity、HUD 文本一致、粒子池上限与强制静音。
- 未验证：浏览器像素级截图比较、真实音频输出、不同机器上的播放帧率。该自测使用插桩 Canvas，不等同于浏览器渲染。
